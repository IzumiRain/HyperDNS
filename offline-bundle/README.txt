راهنمای نصب آفلاین روی هر سرور اوبونتو / دبیان / ردهت (بدون نیاز به اینترنت):

1. فایل های این پوشه را روی سرور لینوکس خود آپلود کنید:
   scp hyperdns install.sh root@YOUR_SERVER_IP:/root/

2. با SSH وارد سرور خود شوید:
   ssh root@YOUR_SERVER_IP

3. دستور نصب آفلاین را اجرا کنید:
   chmod +x install.sh hyperdns
   ./install.sh

تمام! پنل و سرور دی‌ان‌اس بلافاصله روی سرور شما فعال و آماده استفاده می‌شود:
- داشبورد: http://YOUR_SERVER_IP:8080/dashboard
- یوزرنیم/پسورد پیش‌فرض: admin / admin
- دستور ترمینال TUI: hdns
